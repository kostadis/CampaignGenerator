# Spells — Drawmij's instant summons

## Exact Source Appendix

### Chapter 059 — Drawmij's Instant Summons

- Source: `/home/kostadis/out-of-the-abyss/out-of-the-abyss/docs/summaries/059-session-questions-answers-and-a-key.md`
- Original heading: `Drawmij's Instant Summons`

A powerful wizard spell requiring an expensive sapphire as a component, identified during Gyrgum's library research. It marks an object so that it can later be summoned directly to the caster's hand. The DM shared the spell text in the session Discord. The party immediately theorized this as a mechanism for retrieving the stolen High Tower key. The DM noted that the recall would not function while the object was being worn or carried by another creature, including on a lanyard.
