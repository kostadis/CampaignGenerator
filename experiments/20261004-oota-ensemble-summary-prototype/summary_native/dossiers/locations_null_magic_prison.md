### Chapter 067 — Null Magic Prison

- Source: `/home/kostadis/out-of-the-abyss/out-of-the-abyss/docs/summaries/067-session-08-17.md`
- Original heading: `Null Magic Prison`

A specialized containment area within Candlekeep designed to negate all magical abilities. A'lai Aivenmore desperately requests to be placed here, believing it is the only place he can survive Manshoon's reach. He values confinement there more than freedom because neither he nor an attacking wizard should be able to cast within it.
